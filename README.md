# Luma Garden — гостевой сайт

QR-меню и бонусная карта ресторана Luma Garden. Домен `lumagarden.uz`,
отдельный проект на Vercel.

## Данные

**Еда** — своя, лежит в [`data/menu.json`](data/menu.json) и подключается
статически. С кухней The Lokmaco пересечений нет: это разные заведения.

**Бар общий.** Напитки читаются из `menu.json` The Lokmaco в Supabase Storage
при каждом запросе, поэтому правка цен в админке Локмы меняет барную карту
сразу на обоих сайтах. Нужны `SUPABASE_URL` и `SUPABASE_STORAGE_BUCKET`.
Если чтение не удалось, раздел напитков скрывается, еда остаётся.

Правка позиций и цен = правка `data/menu.json` + пуш (Vercel пересоберёт сам).
Админки нет.

**Программа лояльности тоже общая**: та же организация iiko
(`IIKO_ORGANIZATION_ID`) и тот же класс карты Google Wallet
(`lokmaco_loyalty`) — поэтому у гостя один баланс и одна карта на оба
заведения. Программа называется «The Lokmaco · Luma Garden» и подписана так
же в Google Wallet.

> `issuerName` в `lib/google-wallet.ts` обязан совпадать с тем, что отправляет
> деплой `lokmaco-qr`: класс Wallet один, и та отправка, что пришла последней,
> перезаписывает название для всех гостей. Клиент ищется по номеру телефона, cookie сессии привязана к домену,
поэтому на новом домене телефон вводится заново.

## Оформление

Палитра взята с напечатанного меню и менять её нельзя:

| | |
|---|---|
| фон | `#F4F0E4` |
| плашка | `#E2E4D2` |
| тёмная зелень | `#4A5A44` |
| олива | `#5C7048` |
| охра | `#8A5A3B` |
| золото | `#9A7B3E` |
| текст | `#2C2C24` |

Шрифты: Playfair Display — заголовки (названия категорий курсивом), Lora — текст.

Палитра продублирована в `lib/brand.ts` и `app/globals.css` — менять синхронно.

## Маршруты

- `/` — меню. Печатный QR ведёт на корень домена, без пути.
- `/menu` — то же меню.
- `/card` — бонусная карта.
- `/api/card/{register,me,wallet}` — регистрация, сессия, ссылка в Google Wallet.

## Разработка

```bash
npm install
cp .env.example .env.local   # нужно только для бонусной карты
npm run dev
```

Еда читается из репозитория. `SUPABASE_URL` и `SUPABASE_STORAGE_BUCKET`
нужны для барного меню, `IIKO_*`, `GOOGLE_WALLET_*` и `CARD_SECRET` — для
бонусной карты.

## Чего не хватает

- Фотографии блюд: `imageUrl` у всех 67 позиций пустой, карточки текстовые.
- Переводы на uz/en: в печатном меню их нет, сейчас во всех трёх языках
  русский текст.


- Контакты ресторана: адрес, телефон, часы, Instagram, процент обслуживания.
  Заполнить `info` в `lib/brand.ts` — блок в футере появится сам.
- Иконки PWA (`icons` в `app/manifest.ts` пустой). Нужен логотип Luma Garden;
  иконки The Lokmaco брать нельзя.
