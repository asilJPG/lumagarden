# Luma Garden — гостевой сайт

QR-меню и бонусная карта ресторана Luma Garden. Домен `lumagarden.uz`,
отдельный проект на Vercel.

## Как это связано с The Lokmaco

Отдельный деплой, но **данные общие**, без копий и без второго набора:

| Что | Где живёт | Общее с Lokmaco |
|---|---|---|
| Меню (`menu.json`, фото, видео) | Supabase Storage, бакет `lokmaco-uploads` | да, тот же файл |
| Гости, балансы, номера карт | iiko Cloud API, `IIKO_ORGANIZATION_ID` | да, та же организация |
| Класс карты Google Wallet | `lokmaco_loyalty` | да, тот же класс |
| Оформление, тексты, шрифты | этот репозиторий | нет |

Меню редактируется **только** в админке `lokmaco-qr` (`/admin`). Здесь админки нет
намеренно: два редактора одного файла рано или поздно затрут правки друг друга.
Этот сайт читает результат.

Гость, зарегистрированный на сайте Lokmaco, на `lumagarden.uz` вводит телефон
заново — cookie сессии привязана к домену. Клиент в iiko находится по номеру
телефона, поэтому карта, номер и баланс те же самые.

## Оформление

Палитра взята с напечатанного меню и менять её нельзя:

| | |
|---|---|
| фон | `#F4F0E4` |
| плашка | `#E2E4D2` |
| тёмная зелень | `#4A5A44` |
| олива | `#5C7048` |
| охра | `#8A5A3B` |
| золото | `#9A7B3E` |
| текст | `#2C2C24` |

Шрифты: Playfair Display — заголовки (названия категорий курсивом), Lora — текст.

Палитра продублирована в `lib/brand.ts` и `app/globals.css` — менять синхронно.

## Маршруты

- `/` — меню. Печатный QR ведёт на корень домена, без пути.
- `/menu` — то же меню.
- `/card` — бонусная карта.
- `/api/card/{register,me,wallet}` — регистрация, сессия, ссылка в Google Wallet.

## Разработка

```bash
npm install
cp .env.example .env.local   # заполнить значениями из проекта lokmaco-qr
npm run dev
```

Без `SUPABASE_URL` меню читается из `data/menu.json`, которого здесь нет —
это осознанно, чтобы не плодить копию данных. Для локальной работы нужны
переменные Supabase.

## Чего не хватает

- Контакты ресторана: адрес, телефон, часы, Instagram, процент обслуживания.
  Заполнить `info` в `lib/brand.ts` — блок в футере появится сам.
- Иконки PWA (`icons` в `app/manifest.ts` пустой). Нужен логотип Luma Garden;
  иконки The Lokmaco брать нельзя.
